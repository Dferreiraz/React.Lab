## 💻 Sobre o projeto

O **React.Lab** é um laboratório de estudos dedicado ao desenvolvimento Front-End com React, Vite e tecnologias do ecossistema JavaScript.

O projeto funciona como um hub centralizado de aplicações web, reunindo diferentes projetos em uma estrutura modular para praticar componentização, reutilização de código, gerenciamento de estado, navegação entre páginas e integração com APIs.

A proposta é evoluir os fundamentos do desenvolvimento web por meio de aplicações práticas, explorando diferentes layouts, funcionalidades e abordagens de organização de código.

Além do desenvolvimento individual de cada aplicação, o laboratório busca trabalhar com **isolamento de estilos**, garantindo que projetos com identidades visuais distintas possam coexistir sem interferir uns nos outros.

### 🎯 Objetivos do projeto

- Aprimorar os conhecimentos em React e JavaScript moderno.
- Praticar a criação e reutilização de componentes.
- Desenvolver aplicações com Vite.
- Trabalhar com navegação utilizando React Router DOM.
- Explorar o gerenciamento de estado e a comunicação entre componentes.
- Consumir APIs externas e manipular dados dinâmicos.
- Aplicar conceitos de CSS Scoped, variáveis CSS e organização de estilos.
- Utilizar Tailwind CSS em projetos específicos.
- Desenvolver interfaces responsivas e acessíveis.
- Organizar múltiplas aplicações em uma estrutura modular.
- Construir uma base sólida para projetos Front-End mais complexos.

## 🧠 Conceitos praticados

Ao longo dos projetos, o laboratório aborda diferentes fundamentos do desenvolvimento com React.

**React e componentização**

- Criação e reutilização de componentes.
- Props e comunicação entre componentes.
- Renderização dinâmica de elementos.
- Hooks, como `useState` e `useEffect`, conforme a necessidade.
- Organização de componentes e páginas.

**Navegação e gerenciamento de estado**

- Configuração de rotas com React Router DOM.
- Navegação entre páginas e aplicações.
- Gerenciamento de estado local.
- Atualização dinâmica da interface.
- Compartilhamento de dados entre componentes quando necessário.

**Integração com APIs**

- Requisições HTTP.
- Consumo de APIs externas.
- Tratamento de respostas e erros.
- Exibição de dados dinâmicos.
- Estados de carregamento e atualização da interface.

**Desenvolvimento Front-End**

- Estruturação com HTML5 e JSX.
- Estilização com CSS3 e Tailwind CSS.
- Construção de layouts responsivos.
- Separação entre estrutura, estilos e lógica.
- Organização de arquivos e recursos.
- Boas práticas de acessibilidade e experiência do usuário.

## 🏗 Arquitetura do projeto

Um dos principais desafios do React.Lab é integrar aplicações com diferentes estruturas visuais em um mesmo ambiente, reduzindo conflitos entre estilos e preservando a identidade de cada projeto.

### 🎨 Isolamento de CSS

Para minimizar interferências entre as aplicações, o laboratório adota uma abordagem de isolamento baseada em escopos específicos.

**Estratégias utilizadas:**

- **Wrappers exclusivos:** cada aplicação pode utilizar uma classe raiz, como `.viajare-app` ou `.nexcent-app`, para delimitar seus estilos.
- **Variáveis CSS escopadas:** cores, tipografia e outros valores visuais podem ser definidos dentro do escopo de cada aplicação.
- **Organização dos estilos:** os arquivos CSS são estruturados para reduzir a dependência de seletores globais.
- **Tailwind CSS:** quando utilizado, sua configuração pode ser ajustada para atender às necessidades específicas da aplicação.

O objetivo é permitir que projetos com temas claros, escuros ou identidades visuais diferentes coexistam com menos conflitos.

> O isolamento depende da implementação dos seletores, dos estilos globais, dos componentes compartilhados e da configuração de cada ferramenta. Wrappers e configurações específicas ajudam a reduzir conflitos, mas não garantem isolamento absoluto por si só.

### 🧩 Estrutura modular

A organização modular permite manter cada aplicação relativamente independente, facilitando a manutenção, a evolução e a reutilização de componentes.

Essa abordagem também permite que novos projetos sejam adicionados ao laboratório sem exigir que todas as aplicações compartilhem a mesma identidade visual ou organização interna.

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/Dferreiraz/React.Lab.git
```

### 2. Entre na pasta do projeto

```bash
cd React.Lab
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o servidor de desenvolvimento

```bash
npm run dev
```

### 5. Acesse no navegador

Após iniciar o servidor, o Vite exibirá no terminal o endereço local da aplicação, geralmente:

```text
http://localhost:5173/
```

Acesse o endereço indicado pelo terminal para visualizar o laboratório e navegar pelas aplicações disponíveis.

### 📌 Observações

- É necessário ter o Node.js e o npm instalados.
- Execute os comandos no diretório que contém o `package.json`.
- Os scripts disponíveis dependem da configuração do projeto.
- Caso uma aplicação utilize dependências ou comandos próprios, consulte sua documentação específica.
